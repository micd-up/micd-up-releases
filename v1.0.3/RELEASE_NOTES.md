# Mic'd Up v1.0.3

**Release Date:** 2026-02-02

## What's New

AI Recording Mode - New hotkey for AI-powered transcription using OpenAI

## Installation

1. Download `Mic.d.Up-v1.0.3.zip`
2. Unzip the file
3. Drag `Mic'd Up.app` to your Applications folder
4. **First launch**: Right-click → "Open" to bypass Gatekeeper
5. Grant Accessibility and Microphone permissions when prompted

## Requirements

- macOS 14.0 (Sonoma) or later
- Microphone access
- Accessibility permissions (for global hotkey)
